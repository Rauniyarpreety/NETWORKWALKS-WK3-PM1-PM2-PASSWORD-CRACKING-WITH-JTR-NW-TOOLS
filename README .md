# Week 3 Cybersecurity Internship | PDF Password Cracking with John The Ripper and Networkwalks Tools

For Week 3 of my cybersecurity internship with NetworkWalks Academy, I tested password-protected PDFs supplied for the lab. I worked with John the Ripper on Kali Linux and used NetworkWalks' browser-based tools to see how a dictionary test reports a match.

## Tools used

- **Kali Linux** and **John the Ripper (JTR)** for the desktop lab.
- **Johnny**, the graphical interface for John the Ripper, to review the PDF recovery result.
- **NetworkWalks Hash Calculator** to inspect the encrypted PDF and extract its password-verification data.
- **NetworkWalks Dictionary Attack Lab** to observe a wordlist-based password test.

## Results

| Exercise | What I observed |
| --- | --- |
| John the Ripper on Kali Linux | Johnny reported **1 of 1 PDF passwords recovered**, with zero remaining. |
| NetworkWalks tools lab | The built-in list produced a match after **91 of 100 candidates** had been tried. |
| Lab completion | I captured the flags for both exercises. |

## What I learned

The two exercises helped me distinguish hash extraction from password recovery. Extraction provided the data used to check candidate passwords. Recovery happened when the tool found a matching candidate. Seeing a match within a list of just 100 entries made the risk of predictable passwords concrete.

For a sensitive document, I would use a long, unique password generated by a password manager. I would also limit who can access the file and share its password through a separate secure channel.
